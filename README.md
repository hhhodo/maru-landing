# MARU RANCH — 초원에서 식탁까지, 정직한 한우 목장

축산업(한우 사육) 단일 페이지 랜딩. COVE 랜딩의 섹션 구성·그리드·컴포넌트를 그대로 두고
카피와 이미지만 가상의 한우 목장 **MARU RANCH**로 교체했습니다.

- 헤더(고정) → 히어로 → 프로모 스트립 → 축산 철학 타임라인 → 목장 중점 아젠다(4×3) → 소식(3카드) → CTA → 푸터
- 순수 HTML / CSS, `main` push 시 GitHub Pages 자동 배포
- `css/styles.css`는 공용 디자인 키트 원본(수정 안 함), `css/site.css`가 컴포넌트

```bash
python3 -m http.server 8000
```
